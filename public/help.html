Table Planner

A good first draft, then your finishing touches

Start with the few things that really matter. Generate some options, keep the parts you like, then arrange the rest by hand. You know your guests better than the planner does.

Start with fewer rules

For example, fix the wedding party to a top table and leave everyone else free. Then add one useful preference: keep friend groups at the same table, or spread departments across tables.

In a spreadsheet, use headings such as Name, Friend group and Department. Guests with matching values form a group within each column. Choose a purpose for each column in the import preview:

  • Group at the same table: try to keep each friend group together. Big groups may split.
  • Spread across tables: aim for a similar mix of departments at each table, allowing for table sizes.
  • Mix neighbouring seats: discourage guests from the same department from sitting beside each other.
  • Table assignment: fix guests to tables you choose in Setup. For a top table, fill in only those guests’ cells; leave the rest blank.

Each column has one purpose. Blank cells and columns set to Don’t use for seating have no effect. Labels typed after commas in the name list all share one Groups setting; use a spreadsheet for separate purposes.

What wins when rules compete?

The planner uses this order:

  1. Pinned seats and fixed table assignments must be kept. Conflicting assignments must be resolved before generating.
  2. Individual preferences come next: who should sit near whom, who to keep apart, and end-seat preferences. High makes a pair preference count more than Normal, but cannot override a pin or fixed table.
  3. Keeping groups at the same table comes next.
  4. Spreading across tables and mixing neighbours come last.

A better result higher up this list takes priority, even if it makes several preferences lower down worse. Apart from pins and fixed tables, these are things to try for, not promises.

Example: Priya belongs to the University friend group, but you also ask for her to sit next to Jo. The planner may split Priya from her friends to seat her beside Jo. If Priya is pinned at the top table, she stays there even if Jo is elsewhere.

It balances preferences across everyone, rather than finding each person’s ideal seat separately. If Priya has several “sit near” and “keep apart” preferences, they may compete too. More rules do not guarantee a better place for her. If a result surprises you, check pins and fixed tables first, then individual preferences, then column rules. Remove preferences that do not really matter.

Keep the good bits and try again

There is randomness in generation, so another run can give different options. Pin guests whose exact seats you want to keep, then choose Generate more options to rearrange the unpinned guests.

Expect to finish by hand: drag guests to move or swap them, or use the movement controls. Unpin someone before moving them; fixed table assignments still apply. Pin any new placements you want to keep before generating again.

Keep a copy outside this browser

Everything runs in your browser. Changes save automatically there, but do not sync to other browsers or devices. Clearing browser data removes that local copy. Saved plans are also only in this browser.

Share plan creates a link containing a snapshot of your current plan and settings, without saved versions. Keep or send that link. After editing, create and copy a new link: the old one stays unchanged. Anyone with the link can read the included guest details.

For a file containing your work, including saved versions, choose Backup & restore → Download backup. Download a fresh backup after further changes; use Restore backup to open it later.
